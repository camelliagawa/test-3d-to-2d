# STL → 半立体（レリーフ）変換 Web アプリ

3D の STL をブラウザにドラッグ&ドロップし、好きな角度から見た形を **半立体（レリーフ / 2.5D）** に変換して、3D プリント向けの閉じた STL として書き出すツールです。すべての処理がブラウザ内で完結し、インストールやサーバーは不要です。

## 使い方（① → ④）

1. **① 表示** — STL ファイルをビューにドラッグ&ドロップ（またはクリックして選択）。
2. **② 角度決定** — マウスでモデルを回転し、レリーフの「正面」にしたい向きを決めて
   「この角度でプレビュー生成」を押す。プリセット（正面 / 上 / 横）も利用可。
3. **③ プレビュー** — 生成されたレリーフが表示されます。右パネルのスライダーで
   出力幅・深さ・ベース厚み・解像度・深度の強調(γ) を調整するとリアルタイムで更新。
   - **外形**: 「輪郭クリップ」= モデルの形に沿って外形を抜く / 「長方形プレート」= 台座付き
   - **表示**: レリーフ / 元モデルを切替
4. **④ 出力** — 「STL で書き出し」で `relief.stl` をダウンロード。

> 解像度スライダーを変えた場合は、もう一度「この角度でプレビュー生成」を押すと反映されます
> （深度マップの再取得が必要なため）。その他のパラメータは即時反映されます。

## 仕組み

- 指定した視線方向に**正射影カメラ**を置き、モデルの**深度マップ**を float レンダーターゲットに描画。
- 深度を「手前=高い / 奥=低い」の高さに圧縮し（γ で強調を調整）、**前面のハイトフィールド**を生成。
- **背面の平面**と**側壁（スカート）**で閉じ、**watertight（多様体）なソリッド**にします。
- `STLExporter` でバイナリ STL として書き出します。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に静的ビルド（そのまま配布可能）
npm run preview  # ビルド結果のプレビュー
```

## 技術スタック

TypeScript / Vite / Three.js（STLLoader・OrbitControls・STLExporter）

## 既知の制限・今後の拡張

- レリーフは単一視点の深度ベースのため、視線方向で隠れる面（アンダーカット）は表現されません。
- 拡張候補: ストラップ穴あけ、深度圧縮カーブの種類追加、出力寸法のプリセット、メッシュの簡略化。
